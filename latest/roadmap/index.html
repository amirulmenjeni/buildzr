    Roadmap¶

    What we are working on and what we may do next. Planned work is grouped by a target release, a direction and not a promise: there are no dates, and an item can move or be dropped. Which Structurizr features buildzr supports is a separate question; see Structurizr compatibility, where a missing feature does not mean it is planned.

    Planned¶

    Work we intend to do, by the release we are aiming for. A later target is less certain.

    Aiming for 1.2¶

    • Dynamic view animationStep through a dynamic view's interactions one at a time in the viewer.

    Later¶

    • Unattended export with the viewer rendererOptionally export PNG and SVG from the buildzr command with the viewer's renderer in a headless Chromium-compatible browser; only this command needs the browser, not the in-viewer export.
    • Documentation and ADRs in the viewerRead a workspace's documentation and architecture decision records next to its diagrams.
    • Deployment health checks and groupsShow deployment health checks and deployment groups in the viewer's deployment views.
    • Workspace dependency trackingTrack which workspaces depend on each other so changes can be traced across them.
    • Extend a workspace by nameExtend another workspace in the same project by its name instead of its file path or URL.
    • Model diffCompare two versions of a model and see which elements, relationships and views changed.
    • Query interface for AI agentsLet AI agents query a built model through a dedicated interface such as an MCP server.
    • Authentication for shared servingProtect a buildzr serve instance with authentication when it is shared with a team.
    • Remaining Structurizr compatibilityClose lower-priority gaps with the Structurizr DSL that are listed on the compatibility page.
    • Incremental rebuildsRebuild only what a change touches so that editing one element costs a small fixed amount whatever the size of the workspace, with output identical to a full rebuild.

    Launched¶

    Recent releases and what they added.

    1.1.0 · 26 October 2026¶

    • PNG and SVG export from the viewerDownload the diagram on screen as a PNG or SVG image straight from the viewer.
    • Watch mode for buildzr serveRebuild and refresh the viewer automatically when a model file changes.
    • Branding and themes in the viewerApply a workspace's branding and Structurizr themes when the viewer draws its diagrams, with custom typography from licensed bundled fonts or system font stacks; diagram fonts are build-time inputs as their metrics affect layout.

    1.0.0 · 23 October 2026¶

    • 1.0 release readinessThe packaging, documentation and CI checks needed to ship buildzr 1.0 are finished, and 1.0.0 is the first stable release.

    1.0.0rc1 · 22 October 2026¶

    • Custom elements and custom views in the viewerShow custom elements and custom views in the web viewer, alongside the standard C4 views.
    • Jump from elements to deployment instancesNavigate from a software system or container to the deployment instances that run it.
    • Interactive browser demoEdit a buildzr architecture model and explore the rendered viewer side by side, entirely in the browser.
    • Export command for model filesExport JSON, PlantUML, SVG and PNG from workspace model files with a public buildzr command, covering every workspace a file creates or one you pick; Workspace.save() is deprecated in its favour.
    • Switch between workspaces in the viewerPick among the workspaces a model file, a buildzr serve catalog or a Run Code snippet creates, with the selector hidden when there is only one.
    • Bundled viewer font and third-party noticesThe self-contained viewer bundles Inter regular and bold as its default font and adds a local About view and a THIRD_PARTY_NOTICES.txt file preserving dependency licence and copyright notices.

    0.0.35 · 16 October 2026¶

    • Deterministic tag orderTags are now exported in the order they were added, so the output no longer changes from one Python run to the next.

    0.0.34 · 15 October 2026¶

    • PlantUML export fixesPlantUML export now handles dynamic views, deployment view filters and integer style values correctly.

    0.0.33 · 15 October 2026¶

    • Graphviz-free SVG and PNG exportSVG and PNG export can use PlantUML's Smetana layout, which works without Graphviz installed.
    • Export guideA new Export page in the user guide explains every export format and what each one needs.

    0.0.32 · 14 October 2026¶

    • Reliable theme URLsTheme icon URLs now point at the structurizr/themes GitHub mirror because the old Structurizr host stopped resolving.
